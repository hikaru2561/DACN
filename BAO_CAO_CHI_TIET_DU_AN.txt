📱 PHẦN CỨNG (HARDWARE)
================================================================================

1. ESP32-CAM Module
   - Chip: ESP32-S với PSRAM
   - Camera: OV2640 (2MP)
   - WiFi: 802.11 b/g/n
   - GPIO: 32 pins
   - Memory: 4MB Flash + 8MB PSRAM
   - Power: 5V/1A

2. OLED Display (Tùy chọn)
   - Model: SSD1306 128x64
   - Interface: I2C
   - Kết nối: SDA=GPIO21, SCL=GPIO22
   - Thư viện: Adafruit SSD1306

3. Speaker + Amplifier (Tùy chọn)
   - Amplifier: PAM8403
   - Interface: I2S
   - Kết nối: DIN=GPIO25, BCLK=GPIO26, LRC=GPIO27
   - Thư viện: ESP32-audioI2S

4. Computer/Server
   - OS: Windows 10/11, Linux, macOS
   - RAM: Tối thiểu 4GB
   - Storage: Tối thiểu 2GB
   - Network: WiFi/Ethernet

📊 CẤU TRÚC DATABASE
================================================================================

1. Bảng users
   - id: SERIAL PRIMARY KEY
   - name: VARCHAR(100) NOT NULL
   - student_code: VARCHAR(20) UNIQUE NOT NULL
   - department: VARCHAR(50)
   - is_active: BOOLEAN DEFAULT TRUE
   - created_at: TIMESTAMP WITH TIME ZONE

2. Bảng face_embeddings
   - id: SERIAL PRIMARY KEY
   - user_id: INTEGER REFERENCES users(id)
   - embedding: VECTOR(128) NOT NULL
   - confidence: REAL DEFAULT 0.0
   - created_at: TIMESTAMP WITH TIME ZONE

3. Bảng attendance_logs
   - id: SERIAL PRIMARY KEY
   - user_id: INTEGER REFERENCES users(id)
   - timestamp: TIMESTAMP WITH TIME ZONE
   - confidence: REAL
   - device_id: VARCHAR(50) DEFAULT 'web'

4. Indexes
   - idx_users_student_code: Performance optimization
   - idx_face_embeddings_vector: Vector similarity search
   - idx_attendance_logs_timestamp: Time-based queries

🌐 API ENDPOINTS
================================================================================

1. Health Check
   GET /api/v1/health
   - Kiểm tra trạng thái hệ thống

2. Face Detection
   POST /api/v1/detect
   - Phát hiện khuôn mặt trong ảnh
   - Input: Multipart file upload
   - Output: Face detection results

3. User Registration
   POST /api/v1/register
   - Đăng ký người dùng mới
   - Input: name, student_code, department, image
   - Output: User information

4. Check-in
   POST /api/v1/checkin
   - Điểm danh bằng nhận dạng khuôn mặt
   - Input: image file
   - Output: Recognition result

5. User Management
   GET /api/v1/users
   - Lấy danh sách người dùng
   GET /api/v1/users/{user_id}
   - Lấy thông tin người dùng cụ thể

6. Attendance
   GET /api/v1/attendance/logs
   - Lấy lịch sử điểm danh
   GET /api/v1/attendance/stats
   - Lấy thống kê điểm danh
