# 📅 Workflow Dự án: Hệ thống Điểm danh bằng Nhận dạng Khuôn mặt

## 🎯 Mục tiêu
Xây dựng hệ thống điểm danh tự động sử dụng ESP32-CAM, AI nhận dạng khuôn mặt và web interface.

## 🛠️ Công nghệ
- **IoT**: ESP32-CAM (chụp ảnh + WiFi)
- **AI/ML**: Python + DeepFace (nhận dạng khuôn mặt)
- **Database**: PostgreSQL + pgvector (lưu trữ vector)
- **Web**: Streamlit (giao diện quản lý)
- **Hardware**: OLED SSD1306 + Mini Speaker
