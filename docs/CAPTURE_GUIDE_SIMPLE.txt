CÁCH THỨC:
  • Click nút "📸 CHỤP THỦ CÔNG (Space)"
  • Hoặc nhấn phím SPACE trên bàn phím

ĐẶC ĐIỂM:
  ✅ Chụp NGAY LẬP TỨC frame hiện tại
  ✅ KHÔNG kiểm tra chất lượng
  ✅ KHÔNG cần có khuôn mặt trong khung
  ✅ User hoàn toàn kiểm soát

KHI NÀO DÙNG:
  • Muốn chụp góc độ cụ thể
  • Cần kiểm soát từng ảnh
  • Auto mode không hoạt động tốt (do ánh sáng xấu)

LƯU Ý:
  ⚠️ Có thể chụp nhầm ảnh KHÔNG CÓ MẶT
  ⚠️ Có thể chụp ảnh BLUR/MỜ
  → Cần cẩn thận khi sử dụng

QUY TRÌNH TỰ ĐỘNG:
  ┌──────────────────────────────────────────────────────┐
  │ Bước 1: Phát hiện khuôn mặt (Face Detection)        │
  │   → InsightFace AI scan frame hiện tại               │
  │   → Tìm khuôn mặt trong ảnh                          │
  │                                                       │
  │ Bước 2: Kiểm tra điều kiện                           │
  │   ✓ Có khuôn mặt? (face_detected = True/False)       │
  │   ✓ Đủ thời gian chờ? (0.5s kể từ ảnh trước)        │
  │                                                       │
  │ Bước 3: Quyết định                                   │
  │   IF điều kiện OK:                                   │
  │      📸 Chụp ảnh tự động                             │
  │      Log: "Captured X/20 (Conf: 0.98)"              │
  │   ELSE:                                              │
  │      ⏭️ Bỏ qua frame này, chờ frame tiếp             │
  └──────────────────────────────────────────────────────┘

INTERVAL (KHOẢNG CÁCH GIỮA CÁC ẢNH):
  • 0.5 giây = 500ms
  • Tại sao 0.5s?
    → Đủ để người di chuyển đầu/thay đổi góc độ
    → Không quá nhanh (tránh ảnh giống nhau)
    → Không quá chậm (tránh user đợi lâu)

  • Timeline ví dụ:
    0.0s: Ảnh 1 (mặt thẳng)
    0.5s: Ảnh 2 (đầu nghiêng trái)
    1.0s: Ảnh 3 (đầu nghiêng phải)
    1.5s: Ảnh 4 (cười)
    ...
    10.0s: Ảnh 20 ✓ Hoàn thành

TỔNG THỜI GIAN:
  20 ảnh × 0.5s = 10 giây (lý thuyết)
  Thực tế: 12-15 giây (vì không phải frame nào cũng có face)

ƯU ĐIỂM:
  ✅ KHÔNG cần thao tác tay
  ✅ Đảm bảo 100% ảnh CÓ KHUÔN MẶT
  ✅ Ảnh đa dạng (nhiều góc độ khác nhau)
  ✅ Nhanh (10-15 giây cho 20 ảnh)

NHƯỢC ĐIỂM:
  ⚠️ Phụ thuộc AI detection
  ⚠️ Cần ánh sáng tốt
  ⚠️ Nếu face không detect được → không chụp

KHI NÀO DÙNG:
  ✅ Điều kiện ánh sáng TỐOT (trong nhà, có đèn)
  ✅ Muốn chụp NHANH
  ✅ Muốn ảnh CHẤT LƯỢNG CAO

GIẢI THÍCH CHI TIẾT:

[1] CONFIDENCE SCORE (Conf: 0.98)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Ý NGHĨA:
    • Độ tin cậy của AI khi phát hiện khuôn mặt

    • Càng cao = AI càng chắc chắn đó là khuôn mặt

    • AI model (InsightFace) scan ảnh
    • Tìm vùng có thể là khuôn mặt
    • Tính xác suất: vùng đó THỰC SỰ là mặt người
    
  PHÂN LOẠI:
    ┌──────────────┬─────────────────┬──────────────────────┐
    │ Confidence   │ Ý nghĩa         │ Chất lượng           │
    ├──────────────┼─────────────────┼──────────────────────┤
    │ 0.95 - 1.0   │ Rất chắc chắn   │ ✅ Tuyệt vời        │

    └──────────────┴─────────────────┴──────────────────────┘

  VÍ DỤ:
    • Conf: 0.98 → AI 98% chắc đó là khuôn mặt
    • Conf: 0.65 → AI chỉ 65% chắc (có thể lầm)

  LƯU Ý:
    • Conf CAO không có nghĩa ảnh KHÔNG BỊ MỜ
    • Conf CHỈ đo "có phải mặt người không"

Khi button "Chụp" được trigger (manual hoặc auto):

BƯỚC 1: KIỂM TRA DUPLICATE (CHỈ ẢNH ĐẦU TIÊN)
├─────────────────────────────────────────────────────
│ IF photos_taken == 0:  ← Chỉ check lần đầu
│     
│     1. Extract embedding từ frame hiện tại
│        → AI tạo 512-D vector đại diện khuôn mặt
│     
│     2. So sánh với TẤT CẢ users trong database
│        → Tính độ tương đồng (similarity)
│     
│     3. Tìm match tốt nhất:
│        
│        IF similarity > 0.5:  ← Ngưỡng nhận diện
│            
│            A. Match với USER KHÁC:
│               ┌──────────────────────────────────┐
│               │ ⚠️ CẢNH BÁO                      │
│               │                                  │
│               │ Khuôn mặt đã được đăng ký!       │
│               │ 👤 User: Nguyen Van A            │
│               │ 🆔 ID: 123                       │
│               │ 📊 Similarity: 87.5%             │
│               │                                  │
│               │ → TỰ ĐỘNG ĐÓNG WINDOW            │
│               │ → KHÔNG lưu ảnh                  │
│               └──────────────────────────────────┘
│            
│            B. Match với CHÍNH USER NÀY:
│               ✅ "Face belongs to user X"
│               → OK, tiếp tục (re-capture case)
│        
│        ELSE (similarity < 0.5):
│            ✅ Khuôn mặt MỚI
│            → OK, tiếp tục
└─────────────────────────────────────────────────────

GIẢI THÍCH SIMILARITY:
  • Độ tương đồng giữa 2 khuôn mặt
  • Tính bằng Cosine Similarity
  • Công thức: cos(θ) = (A·B) / (||A|| × ||B||)
    
  PHÂN LOẠI:
    ┌──────────────┬────────────────────────────────┐
    │ Similarity   │ Ý nghĩa                        │
    ├──────────────┼────────────────────────────────┤
    │ 0.8 - 1.0    │ Gần như CHẮC CHẮN cùng người   │
    │ 0.6 - 0.8    │ Rất có thể cùng người          │
    │ 0.5 - 0.6    │ Có thể cùng người (ngưỡng)     │
    │ 0.3 - 0.5    │ Khác người                     │
    │ 0.0 - 0.3    │ Hoàn toàn khác người           │
    └──────────────┴────────────────────────────────┘
  
  VÍ DỤ:
    • Similarity = 0.87 (87%)
      → 2 ảnh CÙNG 1 NGƯỜI (99% chắc chắn)
    • Similarity = 0.42 (42%)
      → 2 ảnh KHÁC NGƯỜI

TIMESTAMP:

  • Đảm bảo mỗi file có tên UNIQUE
  • Ví dụ:
    2025-12-07 13:55:23.456
    → 1765088123456
