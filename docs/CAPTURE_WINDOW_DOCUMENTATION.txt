================================================================================
1. TỔNG QUAN CHỨC NĂNG
================================================================================

CAPTURE WINDOW là module chuyên biệt để chụp ảnh mẫu cho người dùng mới trong
hệ thống Face Recognition. Module này đảm bảo chất lượng ảnh training tối ưu
để model AI có thể nhận diện chính xác.

MỤC ĐÍCH:
- Thu thập 20 ảnh khuôn mặt chất lượng cao cho mỗi user
- Đảm bảo 100% ảnh có face (không có ảnh rác)
- Kiểm tra trùng lặp face với database hiện tại
- Tự động train model sau khi chụp xong
- Đồng bộ với Dashboard stream (pause/resume)

THÔNG SỐ CHÍNH:
- Số ảnh mục tiêu: 20 ảnh/user
- Resolution: 1024x768 (XGA - từ ESP32-CAM)
- Face detection accuracy: 99% (InsightFace)
- Auto capture interval: 0.5s
- Duplicate detection threshold: similarity > 0.5

2. LUỒNG HOẠT ĐỘNG (WORKFLOW)
================================================================================

┌─────────────────────────────────────────────────────────────────┐
│ STEP 1: KHỞI TẠO                                                │
└─────────────────────────────────────────────────────────────────┘

1.1. User click "Chụp ảnh" trong User Management Window
1.2. CaptureWindow được khởi tạo với parameters:
     - parent: Cửa sổ cha (UserManagementWindow)
     - user_code: Mã người dùng (VD: "1", "2")
     - user_name: Tên người dùng
     - stream_reader: Shared stream từ Dashboard
     - dashboard: Reference để pause/resume

1.3. Dashboard stream TỰ ĐỘNG PAUSE
     → CaptureWindow độc quyền stream reader
     → Đảm bảo quality tốt nhất, không bị conflict

1.4. Khởi tạo AI models:
     - InsightFace FaceAnalysis (buffalo_l)
       → Face detection với accuracy 99%
     - FaceRecognizer
       → Kiểm tra duplicate face

┌─────────────────────────────────────────────────────────────────┐
│ STEP 2: VIDEO LOOP (Real-time Detection)                        │
└─────────────────────────────────────────────────────────────────┘

2.1. Đọc frame từ stream_reader (30 FPS)
2.2. InsightFace detection:
     faces = self.face_app.get(frame)
     
     IF len(faces) > 0:
         ✅ face_detected = True
         - Vẽ GREEN bounding box xung quanh face
         - Hiển thị confidence score (VD: "Conf: 0.98")
         - Status: "Photos: X/20 | Face OK ✓"
     ELSE:
         ❌ face_detected = False
         - Status: "Photos: X/20 | No Face ✗" (màu đỏ)

2.3. Hiển thị frame real-time trên canvas
2.4. Loop liên tục cho đến khi:
     - Đủ 20 ảnh, HOẶC
     - User đóng window

┌─────────────────────────────────────────────────────────────────┐
│ STEP 3: CAPTURE (2 MODES)                                       │
└─────────────────────────────────────────────────────────────────┘

MODE 1: THỦ CÔNG (Manual Capture)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- User click button "📸 CHỤP THỦ CÔNG" hoặc nhấn SPACE
- Chụp ngay frame hiện tại
- KHÔNG check face detected
  (Cho phép user chụp ngay cả khi không ideal)

MODE 2: TỰ ĐỘNG (Auto Capture) - MẶC ĐỊNH TẮT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- User phải TÍCH checkbox "Tự động chụp (Auto)"
- System kiểm tra:
  
  IF face_detected AND current_time - last_capture_time > 0.5s:
      ✅ Chụp ảnh tự động
      📸 Log: "Captured X/20 (Conf: 0.98)"
  ELSE:
      ⏭️ Skip frame này

- Ưu điểm:
  ✅ Không cần user can thiệp
  ✅ Đảm bảo 100% ảnh có face
  ✅ Interval 0.5s → Đa dạng góc độ

│ STEP 4: SAVE PHOTO (Quality Gate)                               │
└─────────────────────────────────────────────────────────────────┘

Khi save_photo() được gọi:

4.1. CHECK DUPLICATE (CHỈ ẢNH ĐẦU TIÊN)

                     │                                     │
                     │ 👤 Người dùng: Nguyen Van A         │
                     │ 🆔 ID: 123                          │
                     │ 📊 Độ tương đồng: 87.5%             │
                     │                                     │
                     │ Vui lòng sử dụng khuôn mặt khác!    │
                     └─────────────────────────────────────┘
                     
                     → TỰ ĐỘNG ĐÓNG CaptureWindow
                     → KHÔNG lưu ảnh
                 
                 ELSE:
                     ✅ "Face belongs to user X - Continue"
                     → Cho phép re-capture (update ảnh cũ)

4.2. SAVE TO DISK
     ═══════════

     ═════════

     - Progress bar: (photos_taken / 20) * 100%

4.4. CHECK COMPLETION
     ════════════════
     IF photos_taken >= 20:

┌─────────────────────────────────────────────────────────────────┐
│ STEP 5: AUTO TRAIN (Background Thread)                          │
└─────────────────────────────────────────────────────────────────┘

5.1. UI Update:
     - Status: "🧠 Đang trích xuất đặc trưng (Append)..."
     - Progress bar: Indeterminate mode

5.2. Background Thread:
     trainer = ModelTrainer()
     success, msg = trainer.train_user(user_code)
     
     PROCESS:
     ┌────────────────────────────────────────┐
     │ 1. Load existing embeddings.pkl (nếu có) │
     │ 2. Extract embeddings từ 20 ảnh mới     │

     │ 3. Tính MEAN embedding:                 │

     │ 4. Update hoặc Append vào database:     │
     │    - Nếu user_code đã tồn tại → Update  │
     │    - Nếu user mới → Append              │
     │ 5. Save embeddings.pkl                  │
     └────────────────────────────────────────┘

5.3. RELOAD DASHBOARD RECOGNIZER (QUAN TRỌNG!)
     dashboard.recognizer.load_database()
     
     → Dashboard nhận diện NGAY user mới
     → Không cần restart app

5.4. Completion:
     MessageBox:

4. TÍNH NĂNG CHI TIẾT
================================================================================

4.1. DUPLICATE FACE DETECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━
Purpose: Ngăn chặn 1 người đăng ký nhiều tài khoản

Algorithm:
1. Khi chụp ảnh ĐẦU TIÊN (photos_taken == 0)
2. Extract embedding từ frame
3. Compare với TẤT CẢ embeddings trong database
4. IF similarity > threshold (0.5):
   - Tìm thấy match với user KHÁC:
     → Warning + Đóng window
   - Tìm thấy match với CHÍNH user này:
     → OK (re-capture case)
   - Không match (Unknown):
     → OK (face mới)

Benefits:
✅ Bảo vệ tính toàn vẹn database
✅ Ngăn fraud/abuse
✅ Chỉ check 1 lần → Performance tốt

4.2. STREAM SYNCHRONIZATION
━━━━━━━━━━━━━━━━━━━━━━━━━━
Vấn đề: Dashboard và CaptureWindow dùng chung 1 stream

Giải pháp:
- Dashboard.pause_stream():
  → self.is_paused = True
  → Video loop KHÔNG hiển thị frame (bỏ qua)
  → stream_reader VẪN CHẠY (continue đọc frames)

- CaptureWindow sử dụng stream_reader độc quyền
  
- Dashboard.resume_stream():
  → self.is_paused = False
  → Tiếp tục hiển thị

Benefits:
✅ Không conflict
✅ Stream quality tối ưu
✅ Seamless transition

================================================================================
7. XỬ LÝ LỖI & EXCEPTION
================================================================================

7.1. STREAM READER NULL
━━━━━━━━━━━━━━━━━━━━
IF stream_reader is None:
    Log: "❌ No stream_reader!"
    → Wait 0.1s và retry
    → Không crash

7.2. WINDOW CLOSED DURING OPERATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
try:
    if self.window.winfo_exists():
        self.video_canvas.itemconfig(...)
except tk.TclError:
    → Break video loop
    → Graceful exit

7.3. INSIGHTFACE LOAD FAIL
━━━━━━━━━━━━━━━━━━━━━━━
try:
    self.face_app = FaceAnalysis(...)
except:
    self.face_app = None
    → Fallback to Haar Cascade

7.4. DUPLICATE CHECK ERROR
━━━━━━━━━━━━━━━━━━━━━━━
try:
    results = self.recognizer.process_frame(frame)
except Exception as e:
    print(f"⚠️ Duplicate check error: {e}")
    → Bỏ qua check
    → Tiếp tục chụp (non-critical)

7.5. TRAINING FAIL
━━━━━━━━━━━━━━━
IF training fail:
    MessageBox:
    "Chụp ảnh thành công nhưng train thất bại: {error}"
    → Ảnh vẫn được lưu
    → User có thể train lại thủ công

8.3. TRAINER INTEGRATION
━━━━━━━━━━━━━━━━━━━━━

- train_user(user_code): Train 1 user

ModelTrainer process:
1. Load existing embeddings.pkl
2. Extract từ raw/{user_code}/*.jpg
