TRÍCH XUẤT ĐẶC TRƯNG LÀ GÌ?
───────────────────────────
  • Quá trình biến đổi ảnh khuôn mặt → Vector số (512 chiều)
  • Mỗi khuôn mặt → 1 vector duy nhất (giống "vân tay số")
  • Vector này gọi là EMBEDDING

MỤC ĐÍCH:
─────────
  ✅ So sánh 2 khuôn mặt = So sánh 2 vectors
  ✅ Nhanh hơn so sánh trực tiếp ảnh
  ✅ Chuẩn hóa: Tất cả face → cùng format (512-D)

VÍ DỤ TRỰC QUAN:
────────────────
  Ảnh khuôn mặt (1024×768 pixels)
         ↓
  [AI Model: InsightFace]
         ↓
  Embedding Vector (512 số thực)
  [0.123, -0.456, 0.789, ..., 0.234]
         ↓
  Lưu vào database
  
  Khi nhận diện:
  Face mới → Extract embedding → So sánh với database

CÔNG NGHỆ:
──────────
  • Model: InsightFace (buffalo_l)
  • Algorithm: ArcFace
  • Output: 512-dimensional vector
  • Accuracy: 99.8% trên LFW benchmark

KHI NÀO TRAIN?

  2. Click nút "🧠 Trích xuất một người" (manual)
  3. Click nút "🔄 Trích xuất tất cả" (full retrain)

┌─────────────────────────────────────────────────────────────────────┐
│ STEP 4: TÍNH MEAN EMBEDDING (TRUNG BÌNH CỘNG)                      │
└─────────────────────────────────────────────────────────────────────┘

TẠI SAO CẦN MEAN?
─────────────────
  ❌ KHÔNG dùng mean:
     → 1 user = 20 embeddings
     → Database lớn (20x)
     → Nhận diện chậm (phải so sánh 20 lần)
  
  ✅ DÙNG mean:
     → 1 user = 1 embedding (đại diện)
     → Database nhỏ gọn
     → Nhận diện nhanh (chỉ 1 lần so sánh)

CÔNG THỨC:
──────────
  mean_embedding = np.mean(user_embeddings, axis=0)
  
  CHI TIẾT:
    user_embeddings shape: (20, 512)
    axis=0: Trung bình theo HÀNG
    
    Result:
      mean_embedding shape: (512,)
    
    Công thức cho từng dimension i:
      mean[i] = (emb_1[i] + emb_2[i] + ... + emb_20[i]) / 20

VÍ DỤ CỤ THỂ:
──────────────
  Dimension 0:
    Ảnh 1: 0.5
    Ảnh 2: 0.6
    Ảnh 3: 0.4
    ...
    Ảnh 20: 0.55
    
    Mean[0] = (0.5 + 0.6 + 0.4 + ... + 0.55) / 20 = 0.52
  
  → Làm cho 512 dimensions
  
  Kết quả:
    mean_embedding = [0.52, -0.31, ..., 0.78]

Ý NGHĨA:
────────
  • Mean embedding = "khuôn mặt trung bình" của user
  • Bao quát tất cả góc độ, biểu cảm
  • Giảm noise từ ảnh xấu

┌─────────────────────────────────────────────────────────────────────┐
│ STEP 5: NORMALIZATION (CHUẨN HÓA)                                  │
└─────────────────────────────────────────────────────────────────────┘

CODE:
  mean_embedding = mean_embedding / np.linalg.norm(mean_embedding)

GIẢI THÍCH:
───────────
  np.linalg.norm(x) = Độ dài vector (L2 norm)
  
  Công thức:
    ||x|| = sqrt(x[0]² + x[1]² + ... + x[511]²)
  
  Normalization:
    x_normalized = x / ||x||
  
  Kết quả:
    ||x_normalized|| = 1 (unit vector)

TẠI SAO CẦN?
────────────
  1. ĐỂ SỬ DỤNG COSINE SIMILARITY:
     
     cosine_sim(A, B) = (A · B) / (||A|| × ||B||)
     
     Nếu ||A|| = ||B|| = 1:
       → cosine_sim(A, B) = A · B (đơn giản hơn)
  
  2. ĐỂ BẤT BIẾN VỚI SCALE:
     
     Vector [1, 2, 3] và [2, 4, 6] có CÙNG HƯỚNG
     → Sau normalize → GIỐNG NHAU
     → So sánh dựa trên HƯỚNG, không phải độ lớn

VÍ DỤ:
──────
  Before normalization:
    mean_emb = [3.0, 4.0, 0.0, ..., 0.0]
    ||mean_emb|| = sqrt(3² + 4²) = 5.0
  
  After normalization:
    mean_emb = [3/5, 4/5, 0, ..., 0]
             = [0.6, 0.8, 0, ..., 0]
    ||mean_emb|| = 1.0 ✓

3. EMBEDDING VECTOR - KHÁI NIỆM CHI TIẾT
================================================================================

ĐỊNH NGHĨA:
───────────
  Embedding = Vector số đại diện cho khuôn mặt trong không gian 512 chiều

CẤU TRÚC:
─────────
  Type: NumPy array
  Shape: (512,)
  Dtype: float32
  Range: Không giới hạn (thực tế: -10 đến +10)

VÍ DỤ:
──────
  embedding = array([
      0.123,    # Chiều 0
      -0.456,   # Chiều 1
      0.789,    # Chiều 2
      ...       # ...
      0.234     # Chiều 511
  ], dtype=float32)

SO SÁNH 2 EMBEDDINGS:
─────────────────────
  PHƯƠNG PHÁP: Cosine Similarity
  
  Công thức:
    similarity = cos(θ) = (A · B) / (||A|| × ||B||)
  
  Nếu đã normalize (||A|| = ||B|| = 1):
    similarity = A · B (dot product)
  
  CODE:
    sim = np.dot(emb_A, emb_B)
  
  KẾT QUẢ:
    • sim = 1.0: Hoàn toàn giống nhau
    • sim = 0.8-0.9: Rất giống (cùng người)
    • sim = 0.5-0.7: Tương tự (có thể cùng người)
    • sim = 0.0-0.4: Khác nhau
    • sim = -1.0: Hoàn toàn ngược

VÍ DỤ CỤ THỂ:
──────────────
  User A - Ảnh 1: [0.5, 0.3, 0.8, ...]
  User A - Ảnh 2: [0.52, 0.31, 0.79, ...]
  → Similarity: 0.98 (cùng người) ✓
  
  User A: [0.5, 0.3, 0.8, ...]
  User B: [-0.3, 0.7, -0.2, ...]
  → Similarity: 0.15 (khác người) ✓

TẠI SAO 512 CHIỀU?
──────────────────
  • Nhiều hơn: Chính xác hơn nhưng chậm + tốn RAM
  • Ít hơn: Nhanh nhưng thiếu thông tin
  • 512: Sweet spot (balance tốt)

  • 10 users: ~20 KB (pure data) + overhead ≈ 50 KB
  • 100 users: ~200 KB + overhead ≈ 500 KB
  • 1000 users: ~2 MB + overhead ≈ 5 MB

TÓM TẮT

QUY TRÌNH NHANH:
────────────────
  1. User chụp 20 ảnh
  2. AI extract 20 embeddings (512-D vectors)
  3. Tính mean → 1 embedding đại diện
  4. Normalize (||emb|| = 1)
  5. Save vào face_embeddings.pkl
  6. Reload recognizer
  7. ✅ Sẵn sàng nhận diện!

KEY CONCEPTS:
─────────────
  • Embedding: 512-D vector đại diện khuôn mặt
  • Mean: Trung bình 20 vectors → 1 vector
  • Cosine Similarity: So sánh 2 embeddings
  • Normalization: Scale vector về length = 1

2 MODES:
────────
  • train_user: Nhanh, incremental (5s)
  • train_all: Chậm, full rebuild (50s)

OUTPUT:
───────
  face_embeddings.pkl:
    - Structure: {"names": [...], "embeddings": [...]}
    - Size: ~50 KB/user
    - Format: Python Pickle

QUALITY:
────────
  • Intra-class sim: >0.80 (cùng người)
  • Inter-class sim: <0.40 (khác người)
  • Norm: 1.0 (normalized)
